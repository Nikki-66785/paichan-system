📋 我是需求方：怎么提交一条需求

需求方负责「把生产需求讲清楚」：选对类型、填对字段、交期准确，排产才靠谱。

1️⃣ 提交新需求

  1. 进入 📋 需求录入 页，左侧是填表区，右侧是需求列表。
  2. 第一步选产品类型——这一步决定后面出现哪些字段，请对照下表选：
    类型是什么你要准备的关键信息
    CB（细胞库）细胞库新建 / 扩增选「新建 / 扩增」、产线、MCB 或扩增日期
    DP（制剂）水针 / 冻干 / CM / ADC 制剂生产剂型、产线（C7 / CM / SJ2 等）、浓度、瓶规——浓度瓶规必填，冻干剂型还要冻干放大测试信息
    Mab（单抗）单抗原液生产产线（SJ1 / SJ2）；首次生产必填 Titer；MCB 建库必填工艺转移日期
    ADCADC 制剂（字段同 DP）同 DP，另含 LP 放行日期
    APS（培养基模拟灌装）按月份提交的模拟灌装需求产线（C7CM DP / SJ2 ADC / SJ2CM DP 之一）+ 月份（yyyy-MM）+ 剂型
    EQP（设备维护）产线维护窗口仅生产计划可见可选：产线 + 起止日期 + 维护类型
  3. 按提示填写其余字段。交期请尽量真实——系统会拿它和排产完成日期对比，交期太紧会出「交期差异」预警横幅。
  4. 点 提交需求。成功后列表顶部出现你这条需求，状态为「待排产」。
  5. 提交后你可以在列表行上点编辑或删除（仅限本人提交的需求）。已提交且正在排产的需求改内容，可能影响已生成的排产，请谨慎。
⚠️ 小提醒优先级不用填，系统统一按「中」处理（v2.16.0 起）。

2️⃣ 在列表里快速找需求

列表上方有两组筛选项，组合使用可以快速缩小范围：

  • 需求人下拉：只看某个人的需求。
  • 时间字段切换：按「提交时间」还是按「交期」来过滤。
  • 时间范围：全部 / 近 1 周 / 近 1 月 / 近 3 月 / 自定义起止。
🔍 找不到自己以前的需求？九成是时间范围挡住的——把范围切到「全部」再找。交期模式的「全部」与提交时间模式的「全部」看的字段不同，记得两边都试试。

3️⃣ 提交后做什么

  1. 等生产计划排产。排产后切到 📅 排产计划，看甘特图上你的批次排在哪条产线、什么时间（此页对你只读，改不了）。
  2. 如果批次完成时间晚于你的交期，系统会在「📋 需求录入」顶部出橙色预警，或在「📅 排产计划」出横幅——发现交期冲突请主动找生产计划沟通，优先保交期还是保产线节奏，由计划员权衡。
  3. 页面底部有 🔔 APS 排产提醒：告诉你哪几个产线组合的哪几个月还没安排「培养基模拟灌装」。如果你负责提交 APS 需求，请按提醒在需求录入里选「APS」类型按月补齐提交。

🛠️ 我是生产计划：从需求到锁定

你的日常：看需求 → 排产（草案）→ 人工调整 → 确认/锁定。记住一条主线——「自动排产只出草案，锁定才算数」。

1️⃣ 处理需求列表（含批量删除）

  • 在 📋 需求录入 勾选需求行左侧的复选框，表头全选框会跟着变（空 → 半选「—」→ 全选）；底部按钮 🗑️ 删除选中（N） 会实时显示已选数量，没勾选时按钮是置灰禁用的。
  • 批量删除的规则（重要）：已完成的需求 → 只删需求记录，它对应的排产批次保留；未完成的需求 → 连同它的排产批次一起删除。系统会再次弹窗问你确认，看清楚再点。
  • 灰色且不可勾选的行 = 历史锁定批次，不允许批量操作（防止误删已锁定的计划）。

2️⃣ 排产四步：排 → 看 → 调 → 锁

  1. 🚀 立即排产：进入 📅 排产计划，点 🚀 立即排产（有未安排需求时顶部横幅里也有同款按钮）。系统按产能与规则生成草案批次，对应需求变为「待确认」。若产生冲突（如交期不够），页面上方会出现告警横幅逐条说明。
  2. 看：上面甘特图看产线占用节奏，下面批次明细表看每一批的「产线 / 开始 / 下罐(灌装) / 完成」四列（见下方解释）。
  3. 调：甘特图上拖拽批次，或点批次在弹窗里改日期/状态，人工调整冲突批次。把批次改成「中止 / 失败 / 取消」= 终态，该批次不再占产能，只留记录。
  4. 锁：没问题后逐条点 确认，或直接 🔒 排产锁定（确认全部待确认批次）。锁定后这批计划成为已占用产能——以后再次自动排产会绕着它们排，不会被推翻。
✅ 为什么要有「确认 / 锁定」这一步？机器排出来的只是建议。确认锁定 = 人拍板：这些产线时段已经被占了，别动。这是系统「起草与确认解耦」的核心设计，避免自动重排反复推翻已定计划。

3️⃣ 批次表四列怎么看

列含义通俗解释
开始实际开始生产日期这一批什么时候开工
下罐 / 灌装Mab 类=「下罐」（收获）；DP/ADC 类=「灌装」单抗看下罐日，制剂看灌装日
完成生产完成（不含目检包装）车间里生产工序全部干完的日子
包装完成仅正式 DP 显示完成日期 + 包装天数（默认 10 天）
交期对应需求的期望交期拿「完成」和它比，晚了就是预警

「完成」刻意不算包装：不同产线节奏可比、又单独看包装时间——这是对齐《排产逻辑.xlsx》的约定。

4️⃣ APS 排产提醒怎么处理

「📋 需求录入」页最底部的 🔔 APS 排产提醒横幅会列出：哪些产线组合的哪几个月还没有安排培养基模拟灌装批次。

  • 有未安排的月份 → 要么提醒需求方去提交对应月份的 APS 需求，要么你确认该月确实不用排。
  • 提醒的月份范围可在 ⚙️ 规则参数 里调整（比如 C7CM DP 默认提醒 3/8/12 月，可改）。

5️⃣ 快照与排产分析

  • 系统在每次排产后自动存快照，每 2 周存定期快照（含人工调整结果）；你也可手动存关键节点快照。
  • 📈 排产分析 默认对比最近两次快照：看批次日期漂移、新增/取消，掌握计划稳定性。
  • 对比不满意可以回到「📅 排产计划」调整；要留存证据就点 ⬇ 下载快照 导出 Excel。

👀 我是读者：我能看什么

读者通常是审计、领导或临时查看人员。v2.18.3 起，读者进入「📋 需求录入」看到的界面与需求方完全一致（表单、按钮都在），但任何写操作——提交、编辑、删除、排产——点击后都会弹提示「📖 读者权限仅可预览」并被拦下，不会产生任何数据变更。

  • ✅ 可以看：需求列表、排产计划（只读）、排产分析、所有筛选和导出。
  • ❌ 不可以：提交/改/删需求、排产、锁定、进参考数据/规则参数/数据管理/权限管理。
💡 想从「读者」变成「需求方」？请联系生产计划管理员，在「🛡️ 权限管理」里把你的账号角色改为「需求方」——改完不用刷新页面，你的界面会自动更新。

🛡️ 权限管理（管理员 / 生产计划专用）

  1. 点顶部 🛡️ 权限管理 打开账号列表。每行 = 一个云端账号 + 当前角色。
  2. 分配 / 调整角色：行内下拉框选「读者 / 需求方 / 生产计划」，系统自动保存。对方在线时即时生效，无需刷新。
  3. 删除账号的角色（v2.18.5 起）：点行右侧 🗑️ 删除，确认后该账号恢复为「读者」——只收回填报/排产等权限，不会删除云端账号本身，之后可随时重新分配。
  4. 两个保护，注意看提示：
    • 白名单管理员行（如主管理员账号）没有删除按钮——系统保证至少留一个管理员，防锁死。
    • 当前登录账号的删除按钮是置灰的——你不能删除自己。
  5. 底部提示：账号需先在腾讯云控制台「身份验证 → 用户管理」里创建，才能在这里分配角色。

❓ 常见问题

Q1：页面看起来和同事的不一样 / 功能点了没反应？

多半是浏览器缓存了旧版本。请按 Ctrl+F5（Mac 为 Cmd+Shift+R）强制刷新，然后看页面右上角版本标签是否显示 v2.18.6。版本标签消失了 = 还在跑旧缓存。

Q2：我看到「提交 / 排产」按钮，但点了弹提示不让用？

你是「读者」角色。按钮故意显示但点不了，是让你知道系统有哪些功能。联系生产计划管理员提升角色即可。

Q3：删除选中按钮是灰的，点不了？

说明当前没有勾选任何可操作行（0 勾选时按钮真正禁用，这是 v2.18.4 起的安全设计）。先去行首勾选；灰色禁勾的行是历史锁定批次，不能批量操作。

Q4：删除选中的需求会连带删掉排产批次吗？

看需求状态：已完成的需求只删需求记录、对应批次保留（历史数据不动）；未完成的需求会连同它的排产批次一起删除。弹窗确认时会有说明。

Q5：橙色 / 红色横幅是什么意思？

橙色「交期差异」：某些批次的完成日期晚于需求交期，点进去看差几天，找计划员协调；排产告警横幅则说明自动排产时有冲突（如产线被占），需要人工调整。

Q6：APS 排产提醒（页面底部蓝色横幅）要我做什么？

它只是提示"哪些产线组合的哪几个月还没安排培养基模拟灌装"——不是报错。需求方按提醒提交对应月份的 APS 需求，或计划员确认该月不排即可。月份规则可在「⚙️ 规则参数」调整。

Q7：为什么我改了需求/批次，同事那边没变化？

确认已登录云端账号并处于在线状态；权限管理改角色是即时下发的，但需求/批次数据走云端同步，正常是自动的，偶尔需要等几秒或刷新一次。若长期不同步，检查网络与账号登录。

Q8：排产结果和我预期不一样，能手动改吗？

能。自动排产只是草案：在「📅 排产计划」的甘特图上拖拽批次、或点批次弹窗改日期/状态即可；改成「中止/失败/取消」终态的批次不再占产能。改完记得对受影响的批次「确认 / 锁定」。

Q9：会不会有人误删全部数据？

三道保险：① 危险操作前自动备份 Excel 到云端；② 批量删除有二次确认弹窗；③ 历史锁定批次勾选被禁用。加上云端数据在，最大风险也就是删了草稿级记录，可用备份恢复。

📖 小词典

需求（req）
上游提出的一个生产任务，如「做一批 DP 制剂」。
批次（batch）
排产后把需求落到具体产线 + 时间段的产物，一个需求可能拆成多个批次。
草案 / 待确认
自动排产生成的批次，还没人拍板，可被下次重排改变。
锁定
生产计划确认后的批次，作为已占用产能保护起来。
CB / DP / Mab / ADC
四种产品类型：细胞库、制剂、单抗、ADC 偶联药。
APS / EQP
培养基模拟灌装（按月提报）、设备维护（计划员专用）。
下罐（harvest）
