📋 我是需求方：怎么提交一条需求

需求方负责「把生产需求讲清楚」：选对类型、填对字段、交期准确，排产才靠谱。

1️⃣ 提交新需求

  1. 进入 📋 需求录入 页，左侧是填表区，右侧是需求列表。
  2. 第一步选产品类型——这一步决定后面出现哪些字段，请对照下表选：
    下拉里选是什么你要准备的关键信息
    CB 细胞库（MCB/WCB）细胞库新建 / 扩增CB 种类（MCB / WCB）、Henlius 项目号、批次数、规格；MCB 建库必填「正式工艺转移完成日期」（之后 1 个月才可投产）
    Mab DS 原液单抗原液生产产线（SJ1（松江一厂）/ SJ2（松江二厂））、规格、批次类型、项目阶段；首次生产必填 Titer，并要补 Molecule Type / Target / Novelty / mAb subtype / Host Cell Line
    ADC DS 原液ADC 原液生产字段结构与 Mab DS 相同，另可填「LP 放行完成日期」
    DP 制剂水针 / 冻干制剂生产DP 种类（CM 制剂（Mab 来源） / ADC 制剂）、剂型（水针 / 冻干）、产线（C7CM DP（C7车间） / SJ2CM DP（松江二厂））、制剂批量、注射瓶规格——制剂批量与瓶规必填，冻干剂型还要选是否安排冻干放大测试
    APS 培养基模拟灌装按月份提交的模拟灌装需求APS 产线（SJ2 ADC DP / C7CM DP / SJ2CM DP 之一）+ 计划月份（yyyy-MM）+ 剂型；无需填交期（v2.20.12 起交期字段隐藏，按计划月份排产，该月内自动择 8 天并避让已有批次）
    🔧 设备维护保养产线维护窗口仅生产计划可见可选：维护产线 + 维护类型（计划保养 / 临时维修 / 年度大修 / 校验验证）+ 开始日期 + 结束日期；无需填交期（v2.20.11 起自动按维护结束日期排序）。该类型不显示「项目阶段」「需要条件放行」（v2.20.29 起，与 APS 一致——维护窗口不涉及临床阶段）。提交后可直接点本页 🚀 自动排产 生成维护批次，也可到 📅 排产计划 页点 🔄 刷新自动排产
  3. 按提示填写其余字段。交期请尽量真实——系统会拿它和排产完成日期对比，交期太紧会出「交期差异」预警横幅。
  4. 点 ➕ 添加需求。成功后列表顶部出现你这条需求，状态为「待排产」。填错了想重来，点旁边的 清空表单。
  5. 填一半不用担心丢（v2.20.14 起）：填写过程中系统自动暂存草稿，误关页面 / 误刷新会先弹确认；下次打开自动恢复上次未提交的内容，提交成功后草稿自动清除。
  6. 提交后你可以在列表行上点 编辑、📋 复制（把这条需求全部信息回填到上方表单，改一改再添加就是一条新需求）或 删除（仅限本人提交的需求）。已提交且正在排产的需求改内容，可能影响已生成的排产，请谨慎。
⚠️ 小提醒优先级不用你填——需求方统一按默认档处理；由生产计划按项目在需求列表优先级列设 P1–P5（v2.20.8 起，详见 第 4 章），自动排产会优先排高优先级项目。

2️⃣ 在列表里快速找需求

列表上方有两组筛选项，组合使用可以快速缩小范围：

  • 需求人下拉：只看某个人的需求。
  • 时间字段切换：按「提交时间」还是按「交期」来过滤。
  • 时间范围：全部 / 近 1 周 / 近 1 月 / 近 3 月 / 自定义起止。
🔍 找不到自己以前的需求？九成是时间范围挡住的——把范围切到「全部」再找。交期模式的「全部」与提交时间模式的「全部」看的字段不同，记得两边都试试。

列表上方那排按钮依次是：🚀 自动排产（重新排未锁定的批次）、↺ 清空排产结果（保留需求）（把已生成的批次全清掉、只留需求）、⬇️ 导出需求清单 (Excel)；右侧还有 🧹 清理已完成需求记录（删掉全部批次都已完成的需求记录，排产批次保留）与生产计划专用的 🗑️ 删除选中（N）。

3️⃣ 提交后做什么

  1. 提交成功后，系统会立即推送钉钉群通知并@生产计划（v2.19.2 起）——所以生产计划第一时间就知道你的新需求，不用你再去催；之后等排产即可。排产后切到 📅 排产计划，看甘特图上你的批次排在哪条产线、什么时间（此页对你只读，改不了）。
  2. 如果批次完成时间晚于你的交期，系统会在「📋 需求录入」顶部出橙色预警，或在「📅 排产计划」出横幅——发现交期冲突请主动找生产计划沟通，优先保交期还是保产线节奏，由计划员权衡。
  3. 页面底部有 🔔 APS 排产提醒：告诉你哪几个产线组合的哪几个月还没安排「培养基模拟灌装」。如果你负责提交 APS 需求，请按提醒在需求录入里选「APS」类型按月补齐提交。

🛠️ 我是生产计划：从需求到锁定

你的日常：看需求 → 排产（草案）→ 人工调整 → 确认/锁定。记住一条主线——「自动排产只出草案，锁定才算数」。

1️⃣ 处理需求列表（含批量删除）

  • 在 📋 需求录入 勾选需求行左侧的复选框，表头全选框会跟着变（空 → 半选「—」→ 全选）；底部按钮 🗑️ 删除选中（N） 会实时显示已选数量，没勾选时按钮是置灰禁用的。
  • 批量删除的规则（重要）：已完成的需求 → 只删需求记录，它对应的排产批次保留；未完成的需求 → 连同它的排产批次一起删除。系统会再次弹窗问你确认，看清楚再点。
  • 删除是软删除（v2.20.26 起）：记录不会真正从数据库消失，而是打上删除标记后同步给所有设备，因此删除后你在任何电脑上都看不到它了。界面上与真删除完全一样，无需特别操作（详见 Q22）。
  • 灰色且不可勾选的行 = 历史锁定批次，不允许批量操作（防止误删已锁定的计划）。

2️⃣ 排产五步：排 → 看 → 调 → 锁 → 改

  1. 排：在「📋 需求录入」点需求列表上方的 🚀 自动排产（收到他人新需求时，页面顶部横幅也会出现 🚀 立即排产 按钮）。系统按产能与规则生成草案批次，对应需求变为「待确认」。若产生冲突（如交期不够），页面上方会出现告警横幅逐条说明。
  2. 看：上面甘特图看产线占用节奏，下面批次明细表看每一批的状态、产线、开始 / 下罐(灌装) / 完成等（见下方解释）。
  3. 调：甘特图上拖拽批次，或点行内 调整 打开弹窗改日期 / 产线 / 状态，人工调整冲突批次。把批次改成「中止 / 失败 / 取消」= 终态，该批次不再占产能，只留记录。
  4. 锁：没问题后逐条点 确认，或直接 🔒 排产锁定（确认全部待确认批次）。锁定后这批计划成为已占用产能——以后再次自动排产会绕着它们排，不会被推翻。
  5. 改：锁错了或需求变了，勾选批次点 🔓 批量解锁（勾选批次） 放开；再点 🔄 刷新自动排产（重排未锁定批次） 按当前需求整体重排——锁定批次与终态批次保持不变。批次表也支持勾选后 🗑️ 删除选中（N）。
✅ 为什么要有「确认 / 锁定」这一步？机器排出来的只是建议。确认锁定 = 人拍板：这些产线时段已经被占了，别动。这是系统「起草与确认解耦」的核心设计，避免自动重排反复推翻已定计划。

3️⃣ 批次表每列怎么看

列含义通俗解释
状态锁定 / 自动 / 预警 / 人工 / 中止 / 失败 / 取消这批现在是什么身份；后三种是终态
产线 / 批次号占用哪条产线、批次编号批次号人工可改
开始实际开始生产日期这一批什么时候开工
下罐 / 灌装Mab 类=「下罐」（收获）；DP/ADC 类=「灌装」单抗看下罐日，制剂看灌装日
完成生产完成（不含目检包装）车间里生产工序全部干完的日子
包装完成仅正式 DP 显示完成日期 + 包装天数（默认 10 天）
实际完成生产计划在「调整」弹窗里填的真实完成日期（留空 = 还没完成）绿色 = 已填；用来算「实际准不准」（详见 Q18）
交期对应需求的期望交期拿「完成」和它比，晚了就是预警
GMP这批是不是 GMP 生产批次看批次性质

「完成」刻意不算包装：不同产线节奏可比、又单独看包装时间——这是对齐《排产逻辑.xlsx》的约定。

💡 甘特图的几个调节项：左上角可多选产线过滤；时间范围支持 全部 / 近1月 / 近3月 / 近6月 / 自定义；时间轴密度可选紧凑(1.5px/天) / 标准(2.5px/天) / 宽松(4px/天)，批次挤在一起时调紧凑、想看清日期调宽松；刻度可切月 / 周 / 天。这些设置保存在本机，下次打开保持不变。注意：产线筛选只影响甘特图，下方批次明细表左侧那组「类型 / 产线 / 状态 / 时间」下拉是独立的筛选，两者互不影响。

4️⃣ APS 排产提醒怎么处理

「📋 需求录入」页最底部的 🔔 APS 排产提醒横幅会列出：哪些产线组合的哪几个月还没有安排培养基模拟灌装批次。

  • 有未安排的月份 → 要么提醒需求方去提交对应月份的 APS 需求，要么你确认该月确实不用排。
  • 提醒的月份范围可在 ⚙️ 规则参数 里调整（比如 C7CM DP 默认提醒 3/8/12 月，可改）。

5️⃣ 快照与排产分析

  • 快照来源（v2.20.9 起每次排产不再自动存快照）：每 2 周自动存定期快照（含人工调整结果），加上你手动点 📸 保存人工快照 存的关键节点快照（可在旁边填一句备注，如「3月排产会议确认版」）；历史自动排产快照仍保留可查。快照按来源限额保留（自动 10 / 定期 5 / 人工 4）。
  • 批次日期漂移分析：默认对比最近两次快照，看批次日期漂移、新增 / 取消，掌握计划稳定性；也可以用上方的两个下拉任选两次快照来对比。
  • 月度批次趋势：按批次开始日期的月份统计的堆叠柱状图，可按产线筛选、与甘特图时间窗口联动。
  • 排产历史记录（快照管理）：页面下方列出全部快照（序号 / 时间 / 来源 / 需求数 / 批次数 / 预警数 / 准时率），勾选后可点 🗑️ 删除选中（N） 批量删除——删除前系统会自动先下载一份备份，删除后立即同步云端，不用怕刷新被旧快照回填；点 🗑️ 清空快照 则清空全部。要留存证据就点 ⬇ 下载快照 导出 Excel（快照列表 + 批次明细两张工作表）。
  • 对比不满意可以回到「📅 排产计划」调整。

6️⃣ 产能上限与产能情况（v2.20.5 起）

  1. 设上限：在 ⚙️ 规则参数 的「📊 各生产类型上限批次数」卡里，按 10 个类型行（CB / Mab / Mab DS：SJ1 / Mab DS：SJ2 / ADC DS / ADC DP / CM DP·C7 / CM DP·SJ2 / 参比品 / EQP）填写当年上限批次数，留空 = 无上限。上限按年份分开设置（v2.20.11 起）：用「生效年份」下拉切换，默认当年，切换年份各自数值独立；切换时若当前年份有未保存修改会先弹确认（v2.20.12 起）。
  2. 复制上年 / 清空本年（v2.20.13 起）：新年份排产约束通常沿用上年，点 📋 复制上年 一键带入上一年全部上限，再微调即可；点 🧹 清空本年 恢复为不限。
  3. 上限全员共享（v2.20.9 起）：上限随计划数据云端同步，任一生产计划填写后其他同事刷新即可看到，不再只存在本机。
  4. 看产能：在 📈 排产分析 的「产能情况」卡，选年份（默认当年）或自定义起止日期后点「应用」，表格显示每类的上限 / 已用 / 剩余 / 利用率。
  5. 看颜色：利用率 <60% 绿、60–90% 黄、≥90% 红；超出上限的行整行变红并标注「已超出 N 批」——这只是警告，不会拦截排产，由你判断要不要调整。
💡 口径说明「已用」= 时段内所有批次的开始日期落在该区间（含未锁定）。冻干放大测试和 APS 不单独占一行，而是按 batch.line 归入对应产线（SJ2 ADC DP→ADC DP、C7CM DP→CM DP·C7、SJ2CM DP→CM DP·SJ2）；CB 行 = MCB+WCB 之和，EQP 行 = 设备维护+设备验证+贴签包装+包装 之和。

7️⃣ 项目优先级 P1–P5（v2.20.8 起）

  1. 在 📋 需求录入 的需求列表里找到「优先级」列。有项目号的需求行，生产计划可直接在行内下拉选择 P1–P5（P1 最高、P5 最低，默认 P3）。
  2. 优先级是按项目设置的：改一个，该项目全部需求联动生效，并云端同步——其他同事刷新后即可看到；需求方在此列只读。
  3. 设置后需重新点「自动排产」，新顺序才生效：系统按「优先级 → 交期 → 提交时间」排序——优先级高的项目先排；同优先级里交期早的先排；没填交期的排最后。
  4. 集中管理（v2.20.13 起）：⚙️ 规则参数 页新增「🎯 项目优先级」卡，自动汇总需求与批次中的全部项目号统一设置——某项目当前没有需求行时也能在这里改优先级。
  5. 人工调整时顺手改（v2.20.14 起）：点甘特图批次打开「人工调整」弹窗，里面也有「项目优先级」下拉（项目级生效），保存后会提示重新自动排产。
✅ 为什么这么设计？优先级由生产计划统一按项目拍板（需求方不能自填），排产时高优先级项目自动插到前面——这是后续智能排产的基础：先用 P1–P5 定「谁重要」，再由交期和提交时间定「先后」。

👀 我是读者：我能看什么

读者通常是审计、领导或临时查看人员。v2.18.3 起，读者进入「📋 需求录入」看到的界面与需求方完全一致（表单、按钮都在），但任何写操作——提交、编辑、删除、排产——点击后都会弹提示「📖 读者权限仅可预览」并被拦下，不会产生任何数据变更。

  • ✅ 可以看：需求列表、排产计划（只读）、排产分析、所有筛选和导出。
  • ❌ 不可以：提交/改/删需求、排产、锁定、进参考数据/规则参数/数据管理/权限管理。
💡 想从「读者」变成「需求方」？请联系生产计划管理员，在「🛡️ 权限管理」里把你的账号角色改为「需求方」——改完不用刷新页面，你的界面会自动更新。

🛡️ 权限管理（管理员 / 生产计划专用）

  1. 点顶部 🛡️ 权限管理 打开账号列表。每行 = 一个云端账号 + 当前角色。
  2. 分配 / 调整角色：行内下拉框选「读者 / 需求方 / 生产计划」，系统自动保存。对方在线时即时生效，无需刷新。
  3. 删除账号的角色（v2.18.5 起）：点行右侧 🗑️ 删除，确认后该账号恢复为「读者」——只收回填报/排产等权限，不会删除云端账号本身，之后可随时重新分配。
  4. 两个保护，注意看提示：
    • 白名单管理员行（如主管理员账号）没有删除按钮——系统保证至少留一个管理员，防锁死。
    • 当前登录账号的删除按钮是置灰的——你不能删除自己。
  5. 底部提示：账号需先在腾讯云控制台「身份验证 → 用户管理」里创建，才能在这里分配角色。
  6. 未分配的账号会被挡在门外（v2.20.27 起）：账号建好但还没在这里分配角色时，对方登录后只会看到「🔒 账号尚未开通权限」页，不会被默认当成读者放进来。所以给新同事建完账号，记得顺手在这里分配角色——分配完对方页面会自动生效，不用刷新。

❓ 常见问题

Q1：页面看起来和同事的不一样 / 功能点了没反应？

多半是浏览器缓存了旧版本。请按 Ctrl+F5（Mac 为 Cmd+Shift+R）强制刷新，然后看页面右上角版本标签是否显示 v2.20.29。版本标签消失了 = 还在跑旧缓存。

Q2：我看到「提交 / 排产」按钮，但点了弹提示不让用？

你是「读者」角色。按钮故意显示但点不了，是让你知道系统有哪些功能。联系生产计划管理员提升角色即可。

Q3：删除选中按钮是灰的，点不了？

说明当前没有勾选任何可操作行（0 勾选时按钮真正禁用，这是 v2.18.4 起的安全设计）。先去行首勾选；灰色禁勾的行是历史锁定批次，不能批量操作。

Q4：删除选中的需求会连带删掉排产批次吗？

看需求状态：已完成的需求只删需求记录、对应批次保留（历史数据不动）；未完成的需求会连同它的排产批次一起删除。弹窗确认时会有说明。

Q5：橙色 / 红色横幅是什么意思？

橙色「交期差异」：某些批次的完成日期晚于需求交期，点进去看差几天，找计划员协调；排产告警横幅则说明自动排产时有冲突（如产线被占），需要人工调整。

Q6：APS 排产提醒（页面底部蓝色横幅）要我做什么？

它只是提示"哪些产线组合的哪几个月还没安排培养基模拟灌装"——不是报错。需求方按提醒提交对应月份的 APS 需求，或计划员确认该月不排即可。月份规则可在「⚙️ 规则参数」调整。

Q7：为什么我改了需求/批次，同事那边没变化？

确认已登录云端账号并处于在线状态；权限管理改角色是即时下发的，但需求/批次数据走云端同步，正常是自动的，偶尔需要等几秒或刷新一次。若长期不同步，检查网络与账号登录。

Q8：排产结果和我预期不一样，能手动改吗？

能。自动排产只是草案：在「📅 排产计划」的甘特图上拖拽批次、或点批次弹窗改日期/状态即可；改成「中止/失败/取消」终态的批次不再占产能。改完记得对受影响的批次「确认 / 锁定」。

Q9：会不会有人误删全部数据？

三道保险：① 危险操作前自动备份 Excel 到云端；② 批量删除有二次确认弹窗；③ 历史锁定批次勾选被禁用。加上云端数据在，最大风险也就是删了草稿级记录，可用备份恢复。

Q10：需求列表的「优先级」列我改不了 / 显示灰色标签？

这是设计如此（v2.20.8 起）：优先级由生产计划按项目统一设定（P1–P5 行内下拉），需求方和读者只读。想让你的项目优先排产，请联系生产计划把该项目设为更高优先级（如 P1）。

Q11：产能情况表里整行变红、写着「已超出 N 批」，排产是不是被拦住了？

没有拦截——超限只是警告，提醒你该类型在所选时段内的批次已超过「规则参数」里设的上限，由生产计划自行判断：调整排产、提高上限，或确认超额合理后照常执行。

Q12：保存规则 / 保存计划时弹出「云端同步失败」还带一串错误码，怎么办？

（v2.20.9 起）失败提示会透传具体错误原因，不再是空白提示。先把本地修改保住（别关页面，可稍后重试或先导出备份），然后把错误码截图发给系统维护人员定位；若提示与体积相关（如文档过大），去「📈 排产分析 → 快照管理」删除旧快照后再试。

Q13：需求填一半关了页面，内容还在吗？

（v2.20.14 起）在。填写过程自动暂存草稿，误关 / 误刷新时浏览器会先弹确认；下次打开页面自动恢复上次未提交的内容并提示。提交成功后草稿自动清除。

Q14：页面太刺眼，有没有暗色模式？

（v2.20.16 起）有。点顶栏的 🌙 暗色 按钮一键切换全站深色配色（表格 / 弹窗 / 甘特图都会跟着变），偏好保存在本机、刷新后保持；想切回亮色点 ☀️ 亮色 即可。另外打开「📅 排产计划」时甘特图会自动滚动到今天的位置，不用再手动找（v2.20.18 起）。

Q15：每月都要提交差不多的需求，能不重新填一遍吗？

（v2.20.16 起）能。需求列表每行新增 📋 复制 按钮：点击把该条需求的全部信息回填到上方表单，改一改日期 / 批次数量后点「➕ 添加需求」就提交为一条新需求，重复录入不用从头填。

Q16：想看「哪几个月产能会爆」，系统能直接给图吗？

（v2.20.20 起）能。「📈 排产分析」页最上方新增产能负载总览：左边柱状图按月显示已排批次并叠加月均上限虚线（超限月份标红，v2.20.22 起口径为「年度上限 ÷ 12」，见 Q19），右边是 10 类产线的逐月利用率热力图，一眼看出高峰月份与最挤产线。同页还有交期风险清单、项目组合视图、排产调整统计和需求漏斗。

Q17：交期风险里报的「超期天数」是实际延误吗？

（v2.20.21 前的）默认口径不是。系统原本只记录批次的计划起止日期，所以交期风险用的是「计划完成日期 vs 需求交期」，属于计划口径的预警，用于提前干预。v2.20.21 起批次可以填实际完成日期（见 Q18），填了之后交期风险清单会同步显示实际偏差，并新增「实际准时率」汇总卡，真实交付情况一眼可见。

Q18：实际完成日期怎么填？有什么用？（v2.20.21 起）

生产做完后，由生产计划在「📅 批次总览」行内点「✏️ 调整」打开人工调整弹窗，在「实际完成日期」一栏选填实际生产完成的日期（留空 = 还没完成）。填写时有实时校验与提示：不能早于开始日期；填了计划完成日期后，下方会即时显示「比计划早/晚几天」。

它的作用：①「📅 批次总览」新增「实际完成」列，绿色高亮已完成的批次；②导出台账同步带出这一列，交付记录有据可查；③「📈 排产分析」交期风险清单升级为双口径——已填实际完成日期的批次额外显示实际超期天数 / 实际偏差，顶部新增实际准时率与平均实际偏差两张汇总卡，从「计划准不准」升级为「实际准不准」。批次进入中止/失败/取消等终态时同样可以记录实际完成日期。

Q19：产能负载图上的上限线怎么变成十几批了？和我填的上限对不上。（v2.20.22 起）

因为你填的是全年上限，而这张图是月度图。v2.20.22 前图表直接把年度值当月度阈值画线，「全部类型」时还把 10 类相加——例如各类型年度上限合计 169 批，图上线就标成「上限 169」，比任何单月实际值都高得多，柱子被压扁、也永远不会触发超标红色，预警形同失效。

v2.20.22 起统一折算：图上的上限线 = 年度上限 ÷ 12 = 月均上限（如 169 → 14.1 批/月），线尾标注「月均上限 14.1（各类型年度上限合计 169 批）」，热力图分档与红色超标判定同样按月均口径，悬停提示与卡片摘要都会同时给出年度原值，方便和「产能情况」表对照。「产能情况」表与规则参数里的数值口径未变，仍是年度值，不需要重填。

Q20：项目组合视图选了一年，为什么某个项目的时间跨度会跨到别的年份？（v2.20.24 起）

因为筛选口径是批次开始日期落在所选时段内（与「产能情况」表、甘特图时间窗口一致），而每行显示的「时间跨度」是该项目的这些批次最早开始 ~ 最晚完成。所以一个 2026 年才开始、但要到 2027 年才完成的批次，会整体计入「2026 年」，跨度自然显示到 2027 年。

这样设计是为了让「一个批次只归属一个时段」，避免跨年长批次在两年里被重复计数。如果你更想看「某段时间里在做的项目」（允许跨年批次同时出现在两年），说一声可以换成按时间重叠的口径。

Q21：排产调整统计里的「调整次数」是怎么算的？为什么比我印象中少？（v2.20.25 起）

它是严格口径：只有在「人工调整」弹窗里点「保存」成功一次才 +1——无论改的是日期、产线、批次号、备注还是实际完成日期。不算的包括：锁定 / 解锁 / 批量锁定、把批次标为中止 / 失败 / 取消、重新「自动排产」、需求侧的新增与编辑；这些属于状态流转或计划整体重算，不是针对某个批次的调整工作量。

数字偏少的两个原因：① 计数从 v2.20.25 上线那一刻开始逐次记录，升级时系统按审计日志（最近 100 条）尽力回填了历史，日志窗口之外的旧调整无法追溯，所以历史数字应理解为下限；② 多人同时改同一批次时会互相覆盖，理论上可能少记 1 次（本项目协作频率下基本不会遇到）。

另一个容易困惑的点：上方时段选「近 30 天」时，统计用的是按天明细，而明细只保留近 180 天；选「全部」则读累计值，不受此限制。「按操作人」一栏始终是累计口径，不随上方时段变化。

Q22：为什么我删掉的需求，在别的电脑上又出现了？（v2.20.26 起根治）

原因：删除需求后，如果另一台电脑 / 浏览器当时没打开页面，它本机还留着这条旧记录。它下次打开系统时会执行「首次同步」，看到「本机有、云端没有」，就误判成「上次没同步成功的新增需求」，把它重新补传回云端——于是所有人又看到了，状态还回到了「待确认」。

现在的做法：删除改为软删除——记录不会真的从系统里消失，而是打上删除标记并随云端一起同步。本机条目始终存在，就不会再被误判成「新增」补传回去，这条复活链路从根上断掉了。需求列表、条数统计、需求人筛选、自动排产、需求漏斗与全部导出都只统计未删除的需求，删除后的记录不会再出现在任何界面上。

升级后还要做一次：v2.20.26 之前已经复活的那批旧需求，因为当初是真的被删掉了，系统无法自动追溯，需要在任意一台电脑上再删一次——这次删除会带上标记同步到所有设备，之后就不会再出现。用生产计划账号操作一次即可。

补充：软删除的记录会一直留在云端数据库里，不影响任何界面与统计，只占一点存储。如需彻底清空，可联系系统维护人员做一次性清理。

Q23：打开系统只看到一个登录页，里面的内容都看不到了？（v2.20.27 起）

这是刻意的强制登录。此前未登录时，页面会先把自己渲染出来、再盖一层半透明登录框，背后的需求与排产计划其实是能被看到的；现在改为登录前不显示系统任何内容。同时移除了原来的「暂不登录，匿名继续」按钮——那个入口早就失效了，云端控制台的匿名登录一直是关闭状态，点它只会报错。

正常使用流程：用管理员分配的邮箱与密码登录一次即可。浏览器会记住登录状态，刷新页面、第二天再打开都免登录，不会每次都弹。需要换人使用时，点顶栏「☁️」→「🚪 退出并切换账号」。

补充：角色完全由登录账号决定，因此云端模式下顶栏的「当前角色」切换器已整体隐藏，不会再出现「为什么切不动」的困惑。

Q24：同事要用这个系统，账号怎么开通？忘记密码了怎么办？（v2.20.27 起）

开通流程：① 请系统维护人员为单位内的云开发控制台创建该同事的邮箱账号；② 同事用该账号登录后，若看到 🔒 账号尚未开通权限 页面，说明账号已建好但还没分配角色；③ 由生产计划角色的人在顶栏「🛡️ 权限管理」中给这个邮箱分配 读者 / 需求方 / 生产计划 之一——分配后对方页面会自动生效，不需要刷新。

为什么要有「等待开通」这一页：以前未登记的账号会被默认当成「读者」直接放进去，等于任何能登录的人都能看到全部数据。现在改为必须先由管理员明确分配角色才能进入系统。

忘记密码：系统不提供自助找回。请先在仍能登录时点顶栏「☁️」→ 修改密码自助更换；若密码已完全想不起来，需联系系统维护人员在控制台重置。

Q25：页面底部突然冒出一条「页面遇到问题」的提示，是不是坏了？（v2.20.28 起）

这是 v2.20.28 新增的错误提示条，不是中毒也不是系统崩溃。以前页面出错时只会「一片空白」或按钮点了没反应，使用者没法描述、维护人员也拿不到任何线索；现在系统会把出错现场收集起来，显示成页面底部这一条。

怎么处理：点提示条上的「复制诊断信息」，把复制到的内容（页面版本、运行环境、错误位置、浏览器种类等）粘贴发给系统维护人员即可，不需要自己分析。点「查看详情」可以看到完整错误内容，点「关闭」收起提示条。很多时候只是偶发的小问题，刷新页面后就能正常使用。

如果提示的是「云同步组件加载失败」，说明浏览器没能加载到云同步模块（通常是网络、公司代理或防火墙拦截）。此时界面仍可打开，但数据只保存在你这台电脑上，不会与其他同事同步——请务必按提示刷新重试，确认恢复正常后再录入数据。

📖 小词典

需求（req）
上游提出的一个生产任务，如「做一批 DP 制剂」。
批次（batch）
排产后把需求落到具体产线 + 时间段的产物，一个需求可能拆成多个批次。
草案 / 待确认
自动排产生成的批次，还没人拍板，可被下次重排改变。
锁定
生产计划确认后的批次，作为已占用产能保护起来。
CB / DP / Mab / ADC
四种产品类型：细胞库、制剂、单抗、ADC 偶联药。
APS / EQP
培养基模拟灌装（按月提报）、设备维护（计划员专用）。
下罐（harvest）
Mab 类培养结束收获上清的关键节点。
灌装（fill）
DP / ADC 制剂装入瓶/器皿的工序节点。
甘特图
横轴时间、纵轴产线的排产总览图，可拖拽调整。
快照
某一时刻排产计划的完整"照片"，用于对比漂移和留档。
预警 / 交期差异
排产完成时间晚于需求交期的风险提示。
软删除
删除需求时只打「已删除」标记、不真正移除记录（v2.20.26 起）。这样删除能随云端同步传播到所有设备，不会再被其他电脑的旧数据补传回来；界面与统计上的表现和真删除完全一致。
项目优先级（P1–P5）
生产计划按项目设定的优先档位，P1 最高、默认 P3；自动排产按「优先级→交期→提交时间」排序。
产能上限 / 利用率
规则参数里按类型设的全年批次数上限；「产能情况」表显示时段内已用 / 剩余 / 利用率，超限整行红（仅警告不拦截）；「产能负载总览」为月度图，上限线按月均上限（年度÷12）显示。
账号与角色
系统必须先登录才能使用（v2.20.27 起强制登录）。每个账号由生产计划在「🛡️ 权限管理」中分配一档角色：读者仅预览、需求方可提交并维护本人需求、生产计划可排产与数据管理。未分配角色的账号登录后只显示「等待开通」提示页。
