规则说明（依据 排产逻辑.xlsx）

· 流程：需求方填写需求 → 自动排产生成草案 → 生产计划确认可行性并可人工调整 → 确认无误后「排产锁定」（历史计划自动视为锁定产能）。

· CB：固定周二开工，生产周期 10 天，生产间隔 4 天（上批完成 → 下批开始）；同项目 MCB→WCB 间隔 1 个月（按完成日算）；先有 MCB 再有 WCB。

· 所有产品：正式工艺转移 1 个月后才可开始生产。

· Mab：生产周期 = 种子培养 20 天 + 反应器培养 15 天 + 下游纯化 7 天（合计 42 天，需求提报用默认，各段天数由生产计划在人工干预时按项目调整）；批间开始 ≥8 天，下罐批间 ≥10 天（下罐=开始+种子培养+反应器培养），同产线所有批均为硬约束；同项目 MCB 生产后 1 个月才可开始。

· ADC DS：GMP Mab 完成后 2 周、Non-GMP Mab（来源 PD）完成后 1 个月才可生产；LP 放行完成后才可生产；建议在 Mab 下罐后 2 天开始。

· DP：制剂周期 = 准备 + 灌装 + 冻干 + 清场 + 目检包装（目检包装默认 10 天，默认水针 3+1+0+1+10=15 天、冻干 3+1+3~4+1+10=18~19 天，各段天数在人工干预时可调）；放大测试批次（冻干放大测试及批次类型=放大测试的需求）不含包装目检时间（目检按 0 天计）；灌装日期自动计算 = 开始日期 + 准备天数，随开始日期/准备天数自动更新；C7CM DP 同产线清场后 2 天、SJ2 ADC DP / SJ2CM DP 清场后 4 天开始下一批；ADC Non-GMP 与同项目 ADC DS 间隔 1 个月、其余间隔 2 周；需二次稀配时制剂准备 3 天→4 天（周期 +1 天）；冻干项目需在需求中确认是否安排放大测试，正式生产与测试批间隔 2 个月。

· APS 模拟灌装：占用 8 天、当月内任排。C7CM DP 每年 3/8/12 月、SJ2 ADC DP 每年 3/9 月、SJ2CM DP 每年 8/10 月各 1 批（产线当年有生产时自动生成）。

· 批次终态（生产计划人工标记）：批次可标记为 中止 / 失败 / 取消。终态批次不再占用产能（槽位可复用），也不参与锁定/重排，仅保留记录便于追溯；可在人工调整中改回「人工」状态或删除。

· 批量解锁与刷新自动排产：生产计划可在批次表首列勾选多个锁定批次「批量解锁」；「刷新自动排产」按当前需求重新排产所有未锁定批次（锁定批次与终态批次保持不变）。

· 需求导出：需求列表可一键导出 Excel/CSV（项目、类型、批次类型、交期、状态、规格、阶段、预算、首次生产分子信息等全部填报字段）。

· 甘特图视图：产线支持多选过滤；时间轴密度（px/天）与刻度单位（月/周）可调，设置保存在本地。

· 参考数据：「产线情况 / 制剂产能 / 人员配置 / 需求字段矩阵」四张表可修订（生产计划角色），保存后本地持久化。

数据概览

数据管理

· 导出：将需求、排产批次、规则参数保存为 Excel（.xlsx）文件，可在其它电脑导入使用（同时兼容旧版 JSON 文件导入）。

· 重新导入历史计划：从内置的 CM排产计划_20260818.xlsx 数据重建全部历史锁定批次（当前批次将被替换）。

· 文件结构：本系统共 3 个文件——排产系统.html（界面）、scheduling.js（排产引擎）、history_data.js（历史数据）。请放在同一目录，双击 HTML 即可使用。

· 数据存储：本地优先（localStorage）+ 可选云端共享（CloudBase）。配置环境 ID 后，多人提交的需求实时同步、排产计划云端备份；未配置或网络不可用时自动降级为单机模式。清空浏览器缓存会导致本地数据丢失，请定期导出备份。
